# Global Supply Chain Management Dashboard

## Deskripsi
Global Supply Chain Management Dashboard adalah aplikasi berbasis Laravel untuk memonitor supplier dari berbagai negara serta menganalisis risiko supply chain menggunakan data real-time dari berbagai API.

## Fitur

- Dashboard Monitoring
- Supplier Management (CRUD)
- Product Management (CRUD)
- Country Management
- Weather API
- Exchange Rate API
- Inflation API (World Bank)
- GDP API (World Bank)
- Google News RSS
- Risk Monitoring Dashboard

## Teknologi

- Laravel 10
- PHP
- MySQL
- Bootstrap
- REST API

## API yang Digunakan

- Open Exchange Rate API
- wttr.in Weather API
- World Bank API
- Google News RSS

## Cara Menjalankan

```bash
composer install
php artisan migrate
php artisan serve
